# lspci-rs 功能 Backlog

记录日期：2026-08-11
当前状态：list/show/tree + 23 能力解码器 + TUI（树/详情/过滤/着色）已合入 main

## 待选方向（按投入/价值排序）

### 低成本打磨

1. **TUI 配置空间 hex dump** — `d` 键在详情面板切换原始字节视图，复用现有 dump 渲染器
2. **`?` 帮助叠层** — 按键速查浮层
3. **鼠标支持** — 点击选中、滚动、展开/折叠，337 台设备时体验提升明显
4. **窗口 resize 事件处理** — 当前未处理 SIGWINCH

### 中等成本

5. **排序/分组** — 按厂商/类别/总线排序，大拓扑下有用
6. **导出** — TUI 内按键导出当前快照为 JSON 或文本文件
7. **书签/收藏** — 标记设备，按键跳转

### 高投入

8. **厂商专用解码器** — Intel uncore（sg-232e-224 上大量 `<unknown>` 的 Ice Lake 设备）、NVIDIA GPU、AMD NBIO 等。深化"浏览器"定位
9. **setpci 风格写操作** — `w` 键改寄存器，需要权限模型与确认机制，高风险高价值
10. **多域拓扑实测** — 域感知逻辑已修复但未在真实多域主机上验证
11. **快照 diff** — 对比两次快照，观察配置变化
